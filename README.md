# 信用卡违约风险分析与客户分群

## 项目简介
使用 Python/PySpark 对信用卡违约数据进行风险分析和客户分群。

## 技术栈
- Python
- Pandas
- PySpark
- Scikit-learn
- Matplotlib

## 主要结果
- 随机森林分类模型 AUC-ROC = 0.7710
- K-Means 聚类识别 5 类风险客群
- 近期还款状态（PAY_0）是最强风险信号

## 文件说明
- `Credit_Card_Report.pdf`：完整分析报告
- `credit_overdue_analysis_appendend_with_ml_english.ipynb`：Jupyter Notebook 代码文件
